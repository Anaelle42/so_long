# So_long

so_long is a 42 project that consists of creating a small 2D game using MiniLibX.

The player must collect all collectibles and reach the exit while navigating through the map.

## Controls

* `W` / `A` / `S` / `D` : Move
* `ESC` : Quit the game

## Features

* Map parsing
* Player movement
* Collectibles
* Exit
* Move counter
* Sprite rendering with MiniLibX

## Build

```bash
make
```

Run:

```bash
./so_long maps/map.ber
```
